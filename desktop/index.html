TRAINING PROGRAM

培训课程

聚焦人工智能、机器人、工业视觉、数字孪生与智能硬件， 建立面向先进制造岗位能力的职业技能课程体系。

COURSE 01

人工智能训练师

面向人工智能数据、训练、测试与应用场景开展职业技能培养。

COURSE 02

服务机器人应用技术员

围绕服务机器人应用、调试、运行维护与典型场景任务开展实训。

COURSE 03

数字孪生应用技术员

面向数字孪生建模、数据连接、虚实映射及应用场景开展训练。

COURSE 04

工业视觉系统运维员

覆盖图像采集、视觉识别、系统部署、故障分析及运行维护。

COURSE 05

工业机器人系统操作员

围绕工业机器人系统操作、程序运行及典型工作站任务开展实训。

COURSE 06

工业机器人应用技术员

面向工业机器人应用、调试、集成及场景化任务开展职业技能培养。

COURSE 07

智能硬件装调员

覆盖智能硬件装配、调试、检测及综合应用实训。

ABOUT HUABO BASE

基地概况

北京汇博智能实训基地立足北京昌平， 聚焦先进制造、智能制造与人工智能领域技能人才培养。

BASE 01

北京市昌平区先进人才实训基地

面向先进制造领域建设人才培训、实训与实践能力。

BASE 02

北京市先进制造产教评链主企业

联动产业、教育与技能评价资源，推动产教评协同。

BASE 03

实训设备

配置机器人、工业视觉、智能制造及人工智能相关实训条件。

BASE 04

基地位置

基地位于北京市昌平区，可承接培训、实训、研修及实践活动。

BASE 05

技能认证体系

连接职业技能培训、实训与职业技能等级认定相关能力体系。

BASE 06

产业资源

依托汇博机器人及相关产业资源，为课程、实训与项目实践提供支撑。

BASE 07

合作企业

持续拓展院校、企业及产业合作伙伴，形成协同育人网络。
